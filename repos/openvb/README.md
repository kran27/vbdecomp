# OpenVB game reconstruction

Van Buren game source derived from [OpenJE/openvb](https://github.com/OpenJE/openvb),
with original copyright notices retained. The workspace tracks this source directly.

Target: Windows x86, VC7/C++98 and the original SDKs. Startup is incomplete.
See the workspace [README](../../README.md) and [build guide](../../docs/build.md).
