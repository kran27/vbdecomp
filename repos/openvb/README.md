# OpenVB game reconstruction

Van Buren game source derived from [OpenJE/openvb](https://github.com/OpenJE/openvb).
Original source copyright notices are retained. The workspace tracks this source
directly; use its [README](../../README.md) and [build guide](../../docs/build.md).
The current baseline is Windows x86, VC7/C++98 and the selected original SDKs.
The original startup is incomplete. Ports, modern compiler/library alternatives
and the former interactive harness are outside this baseline.

Publication destination: [kran27/openvb](https://github.com/kran27/openvb).
Nothing should be pushed there until explicitly authorized.
